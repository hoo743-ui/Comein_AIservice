# 데모 영상 — 무엇을 찍었고, 그것이 어느 코드인가

이 폴더의 `.mp4` 는 **저장소에 올리지 않는다**(`.gitignore`). 용량이 크고 코드와 함께
버전을 따라갈 이유가 없다. 대신 **무엇을 찍었는지는 여기 남긴다** — 파일이 없는 사람도
목록과 순서를 알 수 있어야 하고, 영상이 실제로 도는 기능을 찍은 것인지 확인할 수 있어야
한다(찍어 둔 화면이 지금 코드와 다르면 그건 시연이 아니라 광고다).

전체 15편 · 합계 약 7.5MB.

## 발표에서 트는 순서

발표는 짧다. 아래 넷이면 "말 한 줄 → 자리" 라는 이 제품의 주장이 다 보인다.

| # | 파일 | 무엇을 보여주나 | 어디서 도는가 |
|---|---|---|---|
| 1 | `로그인창.mp4` | 문이 열리고 인증 카드가 태어나는 입장 연출 | `app/experience/page.tsx` |
| 2 | `일정 저장.mp4` | **말 한 줄이 일정이 된다** — 캡처 → 제안(pending) → 확정 | `ai/router.py` → `POST /api/chat` → Supabase 직행 |
| 3 | `타임테이블.mp4` | 24시간 원 · 세부 시간표 | `parts/DayViews.tsx` |
| 4 | `일정동의.mp4` | 전원이 동의해야 자리가 앉는다 | `0003`·`0005`·`0006`·`0012` |

## 다시 찍어야 하는 것

2026-08-21 에 화면이 여러 곳 바뀌었다(`docs/24` §32). 아래는 **찍어 둔 영상과 지금
화면이 다른 자리**다 — 발표에서 트는 넷에는 해당되지 않지만, 다시 찍는다면 여기부터다.

- `설정.mp4` — 사용 유형 설명 문구가 바뀌었다("기본 장소·라벨 프리셋" → "오늘의 흐름과
  일정이 나뉘는 갈래 이름"). 그리고 이제 고른 값이 새로고침에도 남는다.
- `사람탭 세부사항ㅇ.mp4` · `개인별 채팅.mp4` — 대화 목록 줄에 휴지통이 생겼다.
- `날짜별 원형 테이블.mp4` · `타임테이블.mp4` — 같은 시각이 셋 이상 겹치면
  "○○ 외 2건" 한 줄로 접힌다.
- **아직 영상이 없는 기능**: 캡처 바의 `@` 로 사람을 못 박고, 그 자리의 방이 열리며
  시각을 묻는 한 줄이 들어가는 흐름. 이번에 새로 붙었다(`lib/mention.ts`).
